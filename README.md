# Carta digital 💌

Sitio estático (sin dependencias). Personaliza todo en `config.js`.

## Publicar en GitHub Pages
1. Crea un repositorio en GitHub y sube estos archivos.
2. Settings → Pages → Source: `Deploy from branch` → `main` / `(root)`.
3. En ~1 minuto estará en `https://TU-USUARIO.github.io/NOMBRE-REPO/`.

## Probar local
Abre `index.html` en el navegador (o `python -m http.server`).
